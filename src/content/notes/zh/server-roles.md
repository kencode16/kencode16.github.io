> 「伺服器」通常指軟體角色，不是指某一台機器；同一台實體主機可同時扮演多種角色。常見實體主機品牌：Dell、HPE、Lenovo、Supermicro。

## 一、12 種常見伺服器

### 01 Web Server（網頁伺服器）

- **功能**：接收瀏覽器的 HTTP/HTTPS 請求，回傳網頁內容（像「店面櫃台」）。
- **用途**：架設官網、內部入口網站、Web 系統前端。
- **常見產品**：Nginx、Apache、Microsoft IIS
- **運用場景**：大公司用多台主機加負載平衡；小公司一台即可或用雲端代管；機房中放在 DMZ 區對外服務。

### 02 Application Server（應用程式伺服器）

- **功能**：執行商業邏輯，例如計算、流程、權限判斷（像「後場廚房」，接收 Web 傳來的需求並實際處理）。
- **用途**：ERP、公文系統、差勤系統等後端程式。
- **常見產品**：Tomcat、JBoss/WildFly、Oracle WebLogic、IBM WebSphere、Node.js
- **運用場景**：大公司 Web／AP／DB 三層分離；小公司三者常裝在同一台；機房中 AP 放內網區，不直接對外。

### 03 Database Server（資料庫伺服器）

- **功能**：儲存與查詢結構化資料（SQL）（像「倉庫加倉管員」）。
- **用途**：人事、財務、公文流程等系統資料。
- **常見產品**：Oracle、Microsoft SQL Server、MySQL、PostgreSQL
- **運用場景**：大公司用主從複寫或叢集（高可用）；小公司單機加定期備份；機房中放在保護等級最高的區域。

### 04 File Server（檔案伺服器）

- **功能**：集中存放與分享檔案（網路磁碟機 `\\server\共用`）。
- **用途**：部門共用資料夾、個人資料夾。
- **常見產品**：Windows Server、Synology、QNAP（NAS）、NetApp、Dell EMC
- **運用場景**：大公司用企業級儲存設備；小公司一台 NAS 即可；機房中搭配 AD 權限控管。

### 05 DNS Server（網域名稱伺服器）

- **功能**：把網址（如 `www.example.com`）轉換成 IP（像「電話簿」）。
- **用途**：讓使用者用名稱連線主機，不用記 IP。
- **常見產品**：Windows DNS、BIND、Infoblox；對外常見 HiNet `168.95.1.1`、Google `8.8.8.8`
- **運用場景**：大公司內外部 DNS 分開；小公司由路由器或 AD 兼任；機房中至少 2 台互為備援。

### 06 Mail Server（郵件伺服器）

- **功能**：收信、寄信、存放信件（SMTP／IMAP／POP3）（像「郵局」）。
- **用途**：公司或機關的電子郵件。
- **常見產品**：Microsoft Exchange、Microsoft 365、Google Workspace、Openfind（政府機關常用）、Postfix
- **運用場景**：大公司自建或混合雲；小公司多用雲端信箱；機房中前端加垃圾郵件與防毒閘道。

### 07 Proxy Server（代理伺服器）

- **功能**：代替使用者上網並過濾流量（像「代購兼安檢」）。
- **用途**：網址過濾、上網紀錄、快取加速；反向代理則保護後端 Web。
- **常見產品**：Squid、Broadcom（Blue Coat）、Zscaler、F5（反向代理）
- **運用場景**：大公司所有上網流量強制經過 Proxy；小公司由防火牆兼做；機房中放在出口端。

### 08 Directory Server（目錄伺服器）

- **功能**：集中管理帳號、密碼、群組與權限（像「人事門禁中心」）。
- **用途**：網域登入、單一帳號登入各系統、群組原則（GPO）。
- **常見產品**：Microsoft Active Directory（AD）、Microsoft Entra ID、OpenLDAP
- **運用場景**：大公司多台 DC 加多站台；小公司一台 AD 兼 DNS、DHCP；屬核心系統，停機則全員無法登入。

### 09 DHCP Server（動態主機設定伺服器）

- **功能**：自動發給電腦 IP、閘道、DNS 設定（像「自動分配座位」）。
- **用途**：使用者電腦開機即可上網，不用手動設定 IP。
- **常見產品**：Windows DHCP、Infoblox、ISC Kea；Cisco 路由器／交換器也可兼做
- **運用場景**：大公司各 VLAN 用 DHCP Relay 集中管理；小公司由路由器直接發放；機房中伺服器一律固定 IP，不使用 DHCP。

### 10 Backup Server（備份伺服器）

- **功能**：排程備份與還原資料（像「保險箱」）。
- **用途**：防範勒索病毒、誤刪、硬體故障。
- **常見產品**：Veeam、Veritas NetBackup、Commvault、Acronis、Synology Active Backup
- **運用場景**：大公司採 3-2-1 原則（3 份資料、2 種媒體、1 份異地）加異地備援；小公司用 NAS 加外接硬碟；機房中有磁帶櫃或備份專區。

### 11 Virtualization Server（虛擬化伺服器）

- **功能**：讓一台實體機同時執行多台虛擬機 VM（像「把一棟房子隔成多間套房」）。
- **用途**：節省硬體、部署快速、可做快照與搬移。
- **常見產品**：VMware vSphere/ESXi、Microsoft Hyper-V、Proxmox VE、Nutanix
- **運用場景**：大公司用多台主機加共享儲存組成叢集；小公司 1～2 台 Hyper-V 或 Proxmox；目前機房裡大部分伺服器其實都是 VM。

### 12 NTP Server（網路校時伺服器）

- **功能**：讓所有設備時間一致（像「全公司對時的標準鐘」）。
- **用途**：Log 時間可互相比對；AD 登入（Kerberos）要求時間誤差在 5 分鐘內。
- **常見產品**：Windows w32time、chrony/ntpd、Meinberg、Microchip（GPS 校時設備）
- **運用場景**：大公司由內部 NTP 主機再對外部時間源；小公司直接對外部 NTP；封閉網路無法連外，需用 GPS 校時設備，或指定 AD／核心交換器作為內部時間源。

## 二、伺服器的資料存在哪裡？

**Q：伺服器通常是用磁碟陣列存資料嗎？**

A：不一定。磁碟陣列常用在重要、需要高可用的地方；伺服器存資料主要有四種方式：

| 方式 | 說明 | 常見用途／產品 |
| --- | --- | --- |
| 本機硬碟＋RAID（DAS） | 硬碟直接插在伺服器裡，用 RAID 卡組成 RAID 1/5/6/10 | 小公司或單台伺服器最常見，例如 Web、DNS、DHCP、NTP 等資料量小的伺服器 |
| 磁碟陣列（SAN Storage） | 獨立一櫃的儲存設備，透過光纖（FC）或 iSCSI 連接多台伺服器 | 大公司與機房的資料庫、虛擬化叢集幾乎都用它；Dell EMC PowerStore、NetApp、HPE、IBM、Infortrend（普安） |
| NAS | 透過網路分享檔案（SMB／NFS） | 主要給 File Server 或備份使用；Synology、QNAP |
| 超融合（HCI） | 不買獨立陣列，用軟體把每台伺服器的硬碟串成共享儲存 | Nutanix、VMware vSAN |

**伺服器角色與儲存的對應**：

- 資料庫、虛擬化主機：SAN 磁碟陣列（VM 要能在主機之間搬移）。
- 檔案、備份：NAS 或備份專用儲存。
- 其他輕量服務：本機 RAID 即可。

**容易混淆的觀念**：

- **RAID vs 磁碟陣列**：RAID 是一種技術，磁碟陣列是一種設備；磁碟陣列裡面也是用 RAID 保護資料。
- **RAID 不等於備份**：RAID 只能防硬碟損壞，防不了誤刪與勒索病毒，仍要另外做備份。
