## 一、基本觀念：cd、ls、/dev

- **`cd`**（change directory，切換資料夾）：移動到某個資料夾，作用就像在 Finder 裡點進那個資料夾。
- **`ls`**（list，列出內容）：列出目前資料夾裡有哪些檔案和資料夾。
- **`/dev`**（device，裝置資料夾）：不是指令，而是一個資料夾路徑。系統把每個硬體裝置當成「檔案」放在這裡，例如硬碟 `disk0`、藍牙裝置，以及 USB 轉 Console 線 `cu.usbserial-XXXXXXXX`。

路徑開頭的 `/` 代表從根目錄開始算，也就是「完整路徑」。指令需要指定裝置或檔案時，寫完整路徑最不容易出錯。

**實例：用 Console 線連線 Juniper 交換器**

1. `cd /dev`：進入裝置資料夾
2. `ls`：列出所有裝置，從中找到 Console 線的名稱
3. `screen /dev/cu.usbserial-XXXXXXXX 9600`：透過這條線連到交換器

第 1、2 步可以合併成一行 `ls /dev/cu.*`，不用先 `cd`，結果只會顯示可用的序列埠。

## 二、常用指令一覽

### 1. 移動與查看位置

| 指令 | 用途 | 範例／備註 |
| --- | --- | --- |
| `pwd` | 顯示目前所在的資料夾 | 迷路時先打這個 |
| `cd 資料夾` | 切換到某個資料夾 | `cd /dev` |
| `cd ~` | 回到家目錄 | 即 `/Users/你的帳號名稱` |
| `cd ..` | 回到上一層資料夾 | |
| `ls` | 列出目前資料夾內容 | |
| `ls -la` | 列出全部（含隱藏檔）與詳細資訊 | 可看大小、權限、修改時間 |
| `ls /dev/cu.*` | 只列出名稱符合的項目 | `*` 代表任意字元 |

### 2. 檔案與資料夾操作

| 指令 | 用途 | 範例／備註 |
| --- | --- | --- |
| `mkdir 名稱` | 建立資料夾 | `mkdir 備份` |
| `touch 檔名` | 建立空白檔案 | `touch notes.txt` |
| `cp 來源 目的` | 複製檔案 | 複製資料夾要加 `-r` |
| `mv 來源 目的` | 搬移或重新命名 | `mv a.txt b.txt` |
| `rm 檔名` | 刪除檔案 | ⚠ 不會進垃圾桶，無法復原 |
| `open 檔名` 或 `open .` | 用預設程式開啟 | `open .` 會在 Finder 開啟目前資料夾 |

### 3. 查看檔案內容與搜尋

| 指令 | 用途 | 範例／備註 |
| --- | --- | --- |
| `cat 檔名` | 顯示檔案全部內容 | 適合短檔案 |
| `less 檔名` | 分頁瀏覽長檔案 | 空白鍵翻頁，`q` 離開 |
| `head` / `tail 檔名` | 看檔案開頭／結尾幾行 | `tail -f` 可即時追蹤 log |
| `grep 關鍵字 檔名` | 在檔案中搜尋文字 | `grep -i` 不分大小寫 |
| `find 路徑 -name "名稱"` | 依名稱找檔案 | `find ~ -name "*.docx"` |

### 4. 網路相關（網管常用）

| 指令 | 用途 | 範例／備註 |
| --- | --- | --- |
| `ping IP` | 測試能否連通 | 按 Ctrl+C 停止 |
| `traceroute IP` | 查看經過哪些路由節點 | |
| `ifconfig` | 查看本機網卡與 IP | |
| `nslookup 網域` | 查詢 DNS 解析結果 | |
| `arp -a` | 查看 IP 與 MAC 對照表 | 找同網段設備 |
| `netstat -rn` | 查看本機路由表 | |
| `ssh 帳號@IP` | 遠端登入設備（加密） | `ssh admin@192.168.1.1` |
| `nc -zv IP 埠號` | 測試某個 port 有沒有開 | `nc -zv 192.168.1.1 22` |

### 5. Console 序列埠連線

| 指令 | 用途 | 範例／備註 |
| --- | --- | --- |
| `ls /dev/cu.*` | 找出 USB 轉 Console 線名稱 | |
| `screen /dev/cu.xxx 9600` | 透過 Console 線連線設備 | 一定要寫 `/dev/` 完整路徑 |
| Ctrl+A → K → y | 離開 screen | |
| `screen -ls` | 列出還在執行的 screen | 連不上、顯示 busy 時用 |

### 6. 系統與程式

| 指令 | 用途 | 範例／備註 |
| --- | --- | --- |
| `whoami` | 顯示目前登入的使用者 | |
| `top` | 即時查看程式與 CPU 使用率 | `q` 離開 |
| `ps aux` | 列出所有執行中的程式 | 常搭配 `grep` 使用 |
| `kill PID` | 結束某個程式 | PID 從 `ps` 或 `top` 查 |
| `df -h` | 查看磁碟剩餘空間 | |
| `sudo 指令` | 用管理員權限執行 | 會要求輸入 Mac 密碼，謹慎使用 |

### 7. 好用的快捷操作

| 操作 | 用途 | 範例／備註 |
| --- | --- | --- |
| Tab | 自動補完檔名／路徑 | 打前幾個字按 Tab，避免打錯 |
| ↑ / ↓ | 叫出之前打過的指令 | |
| Ctrl+C | 中斷正在執行的指令 | |
| `clear`（或 Cmd+K） | 清除畫面 | |
| `history` | 列出打過的指令紀錄 | |
| `man 指令` | 查看指令說明手冊 | `man ls`，按 `q` 離開 |

## 三、注意事項

- `rm` 刪除的檔案不會進垃圾桶；加上 `-r` 會連整個資料夾一起刪除，執行前務必確認路徑。
- `sudo` 會用管理員權限執行，不確定用途的指令不要加 `sudo`。
- 指令、檔名都要分大小寫，中間的空格也有意義（空格用來分隔參數）。
- 檔名或路徑中有空格時，要用引號包起來，例如 `cd "My Folder"`。
