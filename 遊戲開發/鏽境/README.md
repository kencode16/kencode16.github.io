# 鏽境 Rustland — 開發紀錄

俯視角動作冒險遊戲，做成網頁 App（PWA），iPhone 用 Safari「加入主畫面」後可以全螢幕遊玩、離線遊玩。

- **遊玩網址**：https://kencode16.github.io/rustland/
- **遊戲程式**：[`public/rustland/`](../../public/rustland/)（push 到 `main` 約 1 分鐘後自動上線）

## 故事

文明崩潰幾百年後，維修機器人 K-3 在廢棄研究所醒來，電量所剩無幾。
為了找到傳說中的「中央電源」，它必須一路往南，穿過守門者 G-0 把守的閘門。

| 根之間 | Boss 前的充電座 |

**Boss 園丁 V-9**（30 HP）
- 身上有葉狀護盾，斬擊打不動（但打護盾可以累積電弧）
- 用電弧射擊打掉地上的 2 個根節點 → 護盾破裂 7 秒，這時才能造成傷害
- 招式：剪刀突刺（先出紅色預告線）、地刺（地上出現紅圈後爆發）、種子散射
- 血量一半：護盾重生、節點重長，招式加快，護盾破裂時間縮短為 5.5 秒

## 系統設計

- **電量 = 血量**：受傷扣 1 格，越沒電畫面越暗。碰到充電座回滿並存檔。
- **衝刺**：0.2 秒無敵，可以越過斷層，冷卻 0.55 秒。
- **斬擊可以打掉子彈**。
- **電弧射擊**：斬擊命中敵人累積電弧（最多 3 格），射擊消耗 1 格，傷害 2，可打遠處開關、砍藤蔓。
- **敵人行為**：每種敵人攻擊前都會先「預告」（閃紅光／發亮），讓玩家有機會反應。
  - 無人機：繞著你飛，閃紅後直線突擊
  - 爬行者：慢慢靠近，發黃光後短衝
  - 砲台：瞄準後三連發散射
- **Boss 守門者 G-0**（28 HP）
  - 衝鋒時全身裝甲，打不動；撞牆會暈眩 → 輸出時機
  - 第一階段：衝鋒、衝鋒、環狀彈幕
  - 血量一半後進入第二階段：衝鋒更快、撞牆時會噴子彈、召喚無人機、螺旋彈幕
- **存檔**：瀏覽器 localStorage，碰充電座、取得道具、清空房間時自動存。

## 操作

- 觸控：左半邊螢幕拖動＝移動；右下「攻擊」「衝刺」「射擊」按鈕；靠近 NPC 按攻擊＝對話
- 鍵盤：WASD／方向鍵、J／空白鍵 攻擊、K／Shift 衝刺、L 射擊、Esc 暫停

## 技術

- 純 HTML5 Canvas + JavaScript，沒有任何外部套件
- 所有美術都由程式繪製（像素風）；音效和背景音樂都用 Web Audio 即時合成（不用任何音檔）
- 世界先畫在低解析度畫布再放大，維持像素感；文字和 HUD 用高解析度繪製
- `sw.js` 採「網路優先」：有網路時永遠拿最新版，沒網路時用快取

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面、選單（標題／暫停／結局） |
| `game.js` | 遊戲引擎：敵人 AI、Boss、戰鬥、繪圖、輸入、存檔、章節流程 |
| `ch1.js`／`ch2.js` | 各章的地圖、區域、劇情台詞、NPC、觸發事件 |
| `music.js` | 背景音樂（lab／forest／boss／boss2／victory 五首，程式即時生成） |
| `manifest.webmanifest` | PWA 設定（名稱、圖示、橫向） |
| `sw.js` | 離線快取 |
| `icon-180.png`／`icon-512.png` | 主畫面圖示 |

## 想改的時候

- **地圖**：`ch1.js`／`ch2.js` 的 `pieces`，用文字畫的（圖例寫在註解裡）
- **劇情台詞**：各章的 `dlg`；共用台詞（取得道具等）在 `game.js` 的 `COMMON_DLG`
- **難度**：敵人血量在 `game.js` 的 `mkDrone`／`mkCrawler`／`mkCrow`… ；Boss 在 `updateG0`／`updateV9`
- **新增一章**：複製 `ch2.js` 改成 `ch3.js`，在 `index.html` 和 `sw.js` 加上檔名

存檔格式 v2 會自動把第一版的存檔轉換過來，不會遺失進度。
